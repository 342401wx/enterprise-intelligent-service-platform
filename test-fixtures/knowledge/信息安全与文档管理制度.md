# 信息安全与文档管理制度

## 1. 文档分级
公司资料分为公开、内部、机密和严格机密四级。员工手册等制度文件通常为内部级；客户合同、薪酬数据、密钥和未公开财务数据属于机密或更高级别。

## 2. 知识库上传
管理员负责创建知识库和配置全局权限；部门负责人可以上传本部门资料，但发布前必须经过管理员审核。普通员工只能上传到明确授权的个人或部门空间，不能发布全局文档。

## 3. 访问和审计
系统按最小权限原则授权。所有文档上传、下载、发布、删除、权限变更和模型调用都要记录操作人、时间、资源 ID 和结果。审计记录至少保留 180 天。

## 4. 敏感信息
API Key、密码、身份证号、银行卡号不得直接写入知识库或聊天内容。发现泄露风险时，应立即停止传播并通知信息安全负责人。

## 5. 规则测试要点
- 普通员工不能发布全局文档。
- 管理员可以查看完整审计记录。
- 查询敏感数据时，应先校验访问权限并避免在回答中暴露密钥。
